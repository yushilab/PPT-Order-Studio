# PPT Order Studio

Read `AI_START_HERE.md` and follow `AGENTS.md` before working on an order. They are the canonical instructions shared by AI environments.

Use the project virtual environment and `python -m pptstudio`. Check local file and terminal capabilities first; if unavailable, use the manual file exchange route in `docs/desktop-ai.md`.

This file is an entry point for environments that read `GEMINI.md`, including supported Gemini CLI setups. It does not imply that the Gemini desktop/web application has local execution access or automatically reads this repository.
